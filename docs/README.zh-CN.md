## 开发与历史记录

源码仓库的 `docs/development/` 保存贡献者验收、发布流程、文档规则及中文需求和计划；
`docs/archive/` 保存绑定提交的历史报告及原始数据。这些内容不进入库归档。
在源码检出中，从 `docs/development/README.zh-CN.md` 或 `docs/archive/README.zh-CN.md`
开始阅读；也可访问[源码仓库](https://github.com/pangbit/moonjsonnet)查阅这些记录。

历史报告保留当时记录的数量、哈希和失败边界，不能代替当前兼容契约，也不表示后续
提交重新执行过每项测试。
