# Historical reports

[Chinese index](README.zh-CN.md) · [Development documentation](../development/README.md)

These commit-bound reports retain their original dates, counts, failure
classifications, recorded hashes and historical scope. Earlier pending items
are not current status. Privacy notices use the report's prose language;
unredacted evidence remains local. JSON results and package manifests preserve
their original bytes and may contain paths from the original source layout.
This archive is excluded from the library package.

The latest source behavior is documented in the [compatibility reference](../reference/COMPATIBILITY.md).
