## 本批实现与测试

`std.sha256(s)` 在 MoonBit 中计算 UTF-8 字节摘要，返回 64 位小写十六进制字符串。
按照 [FIPS 180-4](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.180-4.pdf)
定义的 SHA-256 算法实现，填充字节按位置生成，不复制整份填充后输入；
每轮压缩计入求值步数预算。没有新增 C FFI 或运行时外部命令依赖。

两组新增本地测试在实现前失败，实现后通过，覆盖空串、`abc`、多块消息、
UTF-8、NUL、百万 `a` 的已知答案、错误类型及计算预算。百万字符测试显式增加
测试步数限额，不改变默认限额。7 条新增 Go 用例覆盖这些契约及 55/56、63/64、
119/120、127/128 字节附近的填充边界，全部通过。

原共享 `std.sha256('x')` 输入保留并改为成功断言。C++ v0.21.0 明确报告该函数
仅受 Go 支持，因此以精确 `RUNTIME ERROR` 和本项目摘要值记录为新增参考差异。
原本地未支持错误测试改用尚未实现的 `sha512`，SHA-256 的原输入另有成功回归。
