## 实现契约

`evaluate` 和 `fs.evaluate_file` 接收按名称注册的 `NativeFunction` 以及 trace
回调。native 支持位置/命名参数和高阶调用，未注册名称返回 null。参数按形参
顺序完整转换为 JSON：递归求值可见字段和数组元素，检查对象断言，省略隐藏
字段，拒绝函数。返回容器立即递归复制，未读取字段中的非有限数也会报错；后续
宿主修改原始 JSON 不影响已经返回的值。宿主错误变为调用位置上的 Runtime。
参数转换保存、恢复外层输出计数器，并受输出/步骤/深度限制。

trace 先按形参顺序求值两个参数，再验证消息为字符串，最后输出并返回 rest。
rest 内部的数组元素和对象字段仍然惰性求值。默认输出
`TRACE: filename:line message` 加换行到 stderr；自定义 sink 接收 Location 和原始
消息，导入共享该 sink 和 native 注册表。内建函数的 tailstrict 调用不再额外按
实参书写顺序求值，从而保留 Go 的形参顺序。

不新增外部解释器或运行时依赖；默认 trace 使用已有 POSIX stderr 封装。
公开接口变更由 `moon info` 生成，README 可执行示例和归档消费者验证其调用。

## 保留差异与后续范围
