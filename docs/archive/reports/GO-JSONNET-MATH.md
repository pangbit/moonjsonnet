## 固定参考的浮点运算

参考为 go-jsonnet v0.21.0，提交 `67968688d9952f50662e979fab1bef889d0d3e57`，
Go 1.24.0 ARM64 构建。其二进制 SHA-256：
`adb17765d091d0a774b7efe68604a44eaed827d40041042d48e7d7b524d5a629`。

对照精确版本的 Go 数学源文件并检查固定二进制的 ARM64 指令，确认了多项
融合乘加位置。MoonBit 实现显式保持这些运算顺序，仅通过标量 C `fma` 提供
单次舍入；没有链接或调用参考解释器。巨大角度使用 Payne–Hanek 规约，
覆盖最大有限 double；源码及继承许可记录在 NOTICE 和 licenses 中。

保留参考 `exp_arm64.s` 的最小次正规数边界：`std.exp(-745)` 为 0。
这一结果与通用数学实现可能不同，是固定参考的实际行为。当前证据不证明所有
Go 架构或工具链输出相同。`sqrt`、`hypot`、`log` 使用 MoonBit core；通过了
当前边界与密集输入矩阵，不声称穷举所有浮点输入。
