# 聚合与非有限数值验收

日期：2026-10-02；macOS arm64，Moon 0.1.20260920 / MoonBit v0.10.14+7d59c7ec9，native。
实现提交：`5c69fdd4040cbce4cfd7b120b949d24d63ad09a9`。

`sum`/`avg` 按参考顺序逐项强制求值并累加，拒绝非数字元素；空数组 sum 返回 0，
avg 报错。Go 原生聚合未执行普通算术的非有限值检查，因此本项目保留其 Infinity/NaN。
一元符号、比较、相等性、abs、字符串转换与 manifest 已覆盖这些值。

直接输出使用 `+Inf`、`-Inf`、`NaN`，包括嵌套数组/对象。这些是参考行为，
并非有效严格 JSON；API/CLI/README 已明确说明。返回的 MoonBit Json Number 保留
值及 stringify 拼写。差分新增 `raw-output` 类型，只允许这三个精确标量拼写，
同时校验参考与本项目 exit 0，不把这类输入交给 JSON 解析器或跳过。

数值格式化拒绝非有限操作数，`%s` 保留字符串输出；索引、字符、切片和按位操作
覆盖 NaN/Infinity。切片执行的加法仍检查非有限结果，避免静默截断递进过程。

## 原正 2^63 差异已消除

固定 ARM64 Go 二进制将 NaN 转为 0，将超出 Int64 范围的转换饱和到端点。
本项目先判断 NaN 和端点，仅对范围内数值调用实际转换。正 `2^63` 的按位操作
显式使用 MaxInt64；取反使用相同定义的饱和转换。原始
`bitwise-int64-upper-boundary` 输入保留，由失败转为通过。

这是对固定参考实际行为的显式模拟，未执行越界浮点转换。Go 本身的越界转换行为
依赖实现；本机结果不证明其他 Go 架构一致，跨平台验证仍在整体计划中。
