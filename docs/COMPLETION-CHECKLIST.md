# 整体目标与完成清单

本清单落实 [GO-PARITY](GO-PARITY.md) 的现有目标与完成标准，起点为本地提交
`e420b71e3cba790682bfdb3e2349df254733544b`（2026-10-08）。整体状态仍为未完成。
2026-10-02 扩展后的目标是固定 go-jsonnet v0.21.0 的功能对齐，而非首期子集。
解析、求值、运行时和工具必须由 MoonBit 原生实现；Go/C++ 仅作开发参考。
MoonBit 接口按功能等价，不要求复制 Go 类型。

先执行 `moon info && moon fmt`、适用的零警告检查/普通与 release 测试/参考差分，
核对 `.mbti` 和 `git diff --check`，再显式暂存本阶段路径并创建本地提交。
最终完成核对必须逐行引用同一最终源码版本的证据，不能用一个格式化批次代替
整体完成。
