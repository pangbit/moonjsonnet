## Development and historical records

The source checkout also contains `docs/development/` for contributor validation,
release procedures, documentation policy and Chinese requirements/plans, plus
`docs/archive/` for commit-bound historical reports and their original data.
They are excluded from the library archive. In a source checkout, start with
`docs/development/README.md` or `docs/archive/README.md`; browse the
[source repository](https://github.com/pangbit/moonjsonnet) for these records.

Historical reports retain their recorded counts, hashes and failure boundaries.
They do not replace the current compatibility contract or establish that a later
commit repeated every test.
