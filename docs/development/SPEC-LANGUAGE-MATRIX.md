All 70 named inference rules are enumerated, including specification builtins. The additional prose/grammar rows are an initial obligation inventory, not a claim that every prose/desugaring clause has been decomposed. Populated cells identify manually examined assertions. Empty cells remain unreviewed. Explicit completed-rule reviews below concern only their named judgments; N/A cells have stated in-rule reasons, not missing passing tests. Runtime errors include host Type/Assertion categories after successful parsing. Independent outcomes are in [the initial language report](SPEC-LANGUAGE-EVIDENCE-2026-10-22.md), [recursive binding/comprehension report](SPEC-LANGUAGE-FORMS-EVIDENCE-2026-10-22.md), [application entry-path report](SPEC-LANGUAGE-CALL-EVIDENCE-2026-10-22.md) and [static importstr report](SPEC-IMPORTSTR-STATIC-EVIDENCE-2026-10-22.md); [Go/C++ comparison](SPEC-LANGUAGE-COMPARISON-2026-10-22.md) is separate. Whole-language conformance remains incomplete.

## Completed named-rule reviews

These are recorded manual decisions from constructor case analysis plus executed controls. The tool checks the fixed rule's empty premises, inspected implementation/test hashes and explicit scope; it does not infer semantic correctness or whole-language acceptance.

- **chk-importstr**: The premise-free core static judgment Gamma |- importstr s only. The wildcard constructor arm returns Unit for every string payload/environment; AST conversion preserves the typed leaf. Executed source/handmade controls support the structural case analysis. No in-rule rejecting or runtime premise exists. [Criteria and exclusions](SPEC-IMPORTSTR-STATIC-REVIEW.md).
