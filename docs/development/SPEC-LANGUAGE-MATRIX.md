## Completed named-rule reviews

These are recorded manual decisions from constructor case analysis plus executed controls. The tool checks empty premises for premise-free judgments, or exact fixed statements and premise roles for the explicitly supported conditional, chk-error and chk-unary transfer judgments. The unary record also pins the four-symbol grammar domain. It checks inspected implementation/test hashes and explicit scope; source/name matches do not prove semantic correctness. Transfer judgments assume their child judgments and do not complete other language rules or whole-language acceptance.

- **chk-if**: The chk-if constructor-transfer judgment only, relative to its three child static judgments. The If arm checks a, b and c unconditionally with the identical names/in_object inputs, introduces no binding and preserves each typed child in AST conversion. Executed role/context/leak probes support that case analysis; reused A1/AP6 are not new groups. [Criteria and exclusions](SPEC-CONDITIONAL-REVIEW.md).
- **chk-unary**: The chk-unary static constructor-transfer judgment for the fixed four-symbol grammar, relative to its operand judgment. Unary(_, a) forwards only a to validate with identical names/in_object, preserving symbol/child during conversion and adding no type/evaluation premise. Three new groups exercise both independent entry paths and separate source Syntax, static rejection and runtime Type; US0/UP0 reuse existing controls without new execution counts. [Criteria and exclusions](SPEC-UNARY-STATIC-REVIEW.md).
- **chk-import**: The premise-free core static judgment Gamma |- import s only; reuses the adjacent constructor argument rather than adding duplicate tests. The wildcard ImportFile arm accepts the false/raw-code mode without inspecting names, context or target. AST conversion preserves the typed leaf; existing source/exported-AST creation and I1-I3 boundary controls are reused, not counted as new tests. [Criteria and exclusions](SPEC-IMPORTBIN-BYTES-REVIEW.md).
- **chk-importstr**: The premise-free core static judgment Gamma |- importstr s only. The wildcard constructor arm returns Unit for every string payload/environment; AST conversion preserves the typed leaf. Executed source/handmade controls support the structural case analysis. No in-rule rejecting or runtime premise exists. [Criteria and exclusions](SPEC-IMPORTSTR-STATIC-REVIEW.md).
- **chk-importbin**: The premise-free core static judgment Gamma |- importbin s only; the value-substitution contract is reviewed separately inside CORE-IMPORT. The wildcard ImportBinary arm returns Unit independently of payload/environment, and conversion preserves the typed leaf. Existing creation acceptance is reused; new source/handmade byte tests also construct the leaf before any resolver demand. Runtime loading is not a premise of this rule. [Criteria and exclusions](SPEC-IMPORTBIN-BYTES-REVIEW.md).
- **chk-error**: The chk-error static constructor-transfer judgment only, relative to its single operand judgment. Fail(a) delegates unconditionally to validate(a, names, in_object), introduces no name/type/evaluation condition and preserves its sole child in AST conversion. Two new groups check both independent entry paths; A3/AP4 reuse literal-operand creation/demand controls without adding new test counts. [Criteria and exclusions](SPEC-ERROR-STATIC-REVIEW.md).
- **if-true**: The if-true constructor-transfer judgment, assuming its condition/selected-child premises; adjacent failures are boundary controls. The evaluator computes the condition once, strictly requires Bool, selects yes on true, and continues with that expression. trace_context copies semantic environment fields. Executed event/value/closure/context probes observe the required order and no unselected demand. [Criteria and exclusions](SPEC-CONDITIONAL-REVIEW.md).
- **if-false**: The if-false constructor-transfer judgment, assuming its condition/selected-child premises; adjacent failures are boundary controls. The evaluator computes the condition once, strictly requires Bool, selects no on false, and continues with that expression. Semantic environment fields survive trace_context. New event/value/context probes and reused IU3 observe no unselected request or callback; IU3 is not a new group. [Criteria and exclusions](SPEC-CONDITIONAL-REVIEW.md).
