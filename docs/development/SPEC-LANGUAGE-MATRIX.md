# Language clause matrix

Generated by [spec-language-matrix.mbtx](../../tools/spec-language-matrix.mbtx) from [manual assertion mappings](../../tests/spec-language-coverage.json). Fixed [specification](https://github.com/google/jsonnet/blob/bbb38f1020be1f5aed560928fb839b2c448cefb4/doc/ref/spec.html) and [language reference](https://github.com/google/jsonnet/blob/bbb38f1020be1f5aed560928fb839b2c448cefb4/doc/ref/language.html.md).

All 70 named inference rules are enumerated, including specification builtins. The additional prose/grammar rows are an initial obligation inventory, not a claim that every prose/desugaring clause has been decomposed. Each populated cell identifies manually examined assertions, not a passing status. Empty cells remain unreviewed even if historical tests mention the feature. Runtime errors include host Type/Assertion categories after successful parsing. Independent outcomes are in [the language evidence report](SPEC-LANGUAGE-EVIDENCE-2026-10-22.md); [Go/C++ comparison](SPEC-LANGUAGE-COMPARISON-2026-10-22.md) is separate. No row claims complete conformance.

Reproduce with `moon run --frozen tools/spec-language-matrix.mbtx REFERENCE_DIR EVIDENCE_DIR`; REFERENCE_DIR supplies pinned spec.html and language.md. This command validates assertion locations/hashes and regenerates this matrix; it never infers results or runs upstream tools.
