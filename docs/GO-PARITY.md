# go-jsonnet 整体功能对齐

目标参考：google/go-jsonnet v0.21.0，提交
`67968688d9952f50662e979fab1bef889d0d3e57`。2026-10-02 用户将目标由首期子集
扩展为功能对齐；[首期需求](../MoonJsonnet_REQUIREMENTS.md) 中的子集限制是历史范围，
不能作为当前整体目标已经完成的依据。当前状态：**未完成整体对齐**。

核心解析、求值和运行时仍由 MoonBit 原生实现，不能通过运行 Go/C++ 解释器提供功能。
参考解释器只用于开发验证。MoonBit 嵌入接口按功能提供等价能力，不要求复制 Go 类型。

## 全量标准库清单

通过固定 Go 二进制实际运行 `std.objectFieldsAll(std)`，记录每个成员的名字、类型
和必需参数数目。冻结参考快照为 [go-stdlib-surface.json](../tests/go-stdlib-surface.json)，
包含 163 个成员（包括可反射的内部辅助成员和常量）。本次扩展前注册 42 个，缺少
121 个；加入摘要、集合、对象、数组组合、查找、极值、聚合及数学布尔函数后
注册 156 个，缺少 7 个（继续加入 TOML/YAML 输出）。

[逐项状态表](GO-STDLIB-SURFACE.md) 保留全部成员，缺失项不会因为没有差分用例而消失。
`registered` 仅表示名字、类型和必需参数数目相同，不表示默认值、惰性、错误、边界
或结果已经完全一致。复现命令：

```sh
moon run tools/parity.mbtx ${LOCAL_PATH_012}/jsonnet _build/native/release/build/cmd/main/main.exe
```

工具校验 Go 二进制提交及干净构建元数据、核对冻结快照，输出
`_build/parity/report.json` 和 `stdlib.md`，记录源码提交、工作区状态和二进制哈希。
报告明确 `behavioral_parity_proven=false`；清单生成成功不是兼容验收通过。

## 功能差距与推进顺序

下表来自本地固定参考的 `--help`、`vm.go`、标准库反射，以及本项目实际 API/CLI。
“部分”也属于未完成；完成一项必须同时补充行为测试和差分证据。

| 范围 | 当前状态 | 后续实现与验收 |
| --- | --- | --- |
| 语言核心 | 已实现主要语法和求值，完整语言等价尚未证明 | 扩大 Go 上游语言/错误/惰性语料覆盖；保留已知差异 |
| 数值、布尔标准函数 | 数学、比较、聚合、谓词已注册并覆盖当前边界语料 | 持续扩大数值语料与跨平台验证，注册不代表全部输入等价 |
| 数组、集合、对象 | 对应标准库成员已注册；新增删除与内部对象合并 | 扩大惰性/副作用边界，保留参考崩溃差异；注册不代表完整行为等价 |
| 字符串、编码、摘要 | 字符串、整数解析、转义、大小写、拆分及 UTF-8/Base64 已加入；摘要仍部分缺失 | 其余摘要函数，以及更广泛输入验证 |
| 输出标准函数 | JSON、INI、Python、XML JSONML、YAML 和 TOML 对应成员已注册 | 扩大输出边界与诊断验证，保留 YAML 参考崩溃差异 |
| 扩展参数 | JSON 值和字符串 | `ExtCode` 真正求值 Jsonnet；文件/环境变量参数、重置语义 |
| 顶层参数 TLA | 缺失 | 字符串/代码参数及顶层函数调用、默认值、错误传播 |
| 原生回调与 trace | 缺失 | 宿主函数注册、`std.native`、可配置 trace 输出 |
| 导入器 | 有定制文本/二进制解析及限定目录文件宿主 | `-J`、`JSONNET_PATH` 搜索顺序、依赖发现、导入查询接口 |
| 输入模式 | 文件和库内源码求值 | CLI `-e`、stdin、`--`、选项缩写；诊断文件名行为 |
| 输出模式 | 单个 JSON/文件 | 字符串输出、multi、stream、目录创建及对应嵌入方法 |
| CLI 参数兼容 | 部分 | 与参考完整 help 逐项核对，包括 `--output-file`、stack/trace 选项 |
| VM/AST 接口 | 一次性 evaluate | 可重用 VM、AST 解析/执行、缓存生命周期、依赖扫描的 MoonBit 等价接口 |
| 格式化器、静态分析工具 | 缺失 | 单独建立格式化/lint/工具接口语料，纳入整体覆盖状态 |
| 平台与交付 | native；实测 macOS arm64 | Linux 持续验证；其余参考平台和分发能力逐项核验，不凭本机结果推断 |

推进顺序：先标准库基础/集合对象能力，再参数、导入、输入输出及宿主接口，随后
格式化和分析工具，持续补齐语言边界与平台验证。`sha256` 消除现有差分中的最后一项
未支持函数，但远非完成标准库；全量清单仍有 7 个缺失成员：`md5`、`sha1`、
`sha512`、`sha3`、`parseYaml`、`native`、`trace`。

已处理的聚合数值边界：保留 Go `sum`/`avg` 的 Infinity/NaN，覆盖传播、比较、转换、
格式化拒绝与非 JSON 标量输出。正 `2^63` 的旧差异通过显式模拟固定 ARM64 参考的
转换结果消除，没有执行越界转换；其他平台的 Go 转换行为仍待验证。

数学新增 29 个成员，覆盖负数舍入、次正规数分解、巨大角度、数值域错误、
命名参数及非有限输入。三角函数、指数与幂按固定 Go 1.24.0 ARM64 算法执行，
显式保留融合乘加与最小次正规数处的行为；未通过放宽比较精度消除差异。
数学批次新增 51 项 Go 输入全部通过。

字符串批次新增 22 个成员、44 项 Go 输入，完整差分为 509/512；既有 3 项
内部崩溃差异保留。Unicode 简单大小写折叠使用校验过 SHA-256 的 Go 1.24.0
Unicode 15.0.0 数据，2,880 组映射在参考和本项目上均验证通过。十进制解析
先检查 Int64 边界，再转换到 double；strip 参数求值、字符集合数组和 splitLimit
整数边界均按 Go 原生覆盖行为实现，而非仅启用同名源码定义。

UTF-8/Base64 批次新增 5 个成员和 37 项 Go 输入，批次差分为 546/549，
既有 3 项内部崩溃差异仍保留。覆盖每个单字节值和 1,536 组双字节输入，
按 Go 规则逐字节替换非法 UTF-8，保留 BOM；Base64 保留原始长度检查、
仅忽略 CR/LF、非零填充位及 Latin-1 字符串以 UTF-8 字节编码等边界。

输出批次新增 6 个成员和 35 项 Go 输入，其中 34 项通过；当时完整差分为
580/584。JSON 原生遍历保留默认参数、任意缩进/分隔符、空容器的双换行、
U+2028/U+2029 转义和隐藏字段惰性。Python、INI、XML JSONML 执行固定标准库
源码。新增循环对象输入使 Go 原生 JSON 输出发生致命栈溢出（退出 2），
本项目返回深度 Limit；该第 4 项差异继续保留为失败，不计为通过。

删除/内部合并批次新增 3 个成员和 47 项输入，35 项通过，12 项触发参考内部
崩溃。当时完整差分为 615/631，16 项失败全部保留，未跳过输入。`removeAt`
按 Go 行为改写原数组槽位后复制缩短结果；`map`/`mapWithIndex`/slice 延迟读槽位，
filter 在谓词执行后读取选中的槽位。内部合并保留字段绑定、可见性和 self，移除
断言。Go 的顶层对象字面量带隐式 `$` local，直接调用内部合并会崩溃；嵌套对象
和对象推导式的正常调用已通过差分。3 项删除越界和 9 项内部合并崩溃不算通过。

TOML/YAML 批次新增 4 个成员和 41 项输入，其中 40 项通过；当前完整差分为
655/672，17 项失败均为保留的参考崩溃差异。原生 MoonBit 输出实现保留空 TOML
键、表分组前的求值顺序、YAML 数字/键识别、块字符串和默认参数。Go YAML 会
吞掉对象内递归输出的错误；最后一个字段可返回部分文本，后续字段求值则可能
触发内部栈状态崩溃。两种情况分别保留输入，资源限制错误始终传播。

集合与合并使用固定 Go 参考内嵌的 Apache-2.0 Jsonnet 标准库源码，由本项目
MoonBit 求值器执行。每次 evaluate 解析一次，导入共享 AST，各文件的 `thisFile`
独立绑定。仅启用已验证依赖的成员，原生函数覆盖对应字段；源码提取工具校验参考
提交和源文件状态，来源与许可保留在 NOTICE 和内嵌头部。

## 完成标准

1. 所有参考成员和 CLI/嵌入/工具能力均有实现与对应测试，或有用户明确接受的例外。
2. 对照运行保留成功、错误、未支持、行为差异的独立计数；不能移除失败输入来达标。
3. 测试覆盖默认/命名参数、惰性、Unicode、继承、资源预算和异常边界。
4. 实现提交与验收记录绑定；本地、跨平台、远端 CI、发布分别记录，不相互替代。
5. 17 项已知 Go 崩溃输入继续保留：`tailstrict` 默认参数、`objectRemoveKey` 的
   继承对象与对象局部绑定、循环对象 JSON 栈溢出、3 项删除越界、9 项内部合并及
   YAML 嵌套错误后的栈状态。
   不复制崩溃；是否作为最终兼容例外另行明确。
