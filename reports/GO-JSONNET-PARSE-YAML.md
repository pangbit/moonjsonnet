## 实现与来源

YAML 块/流集合、普通/引号/块标量、锚点和标签语法由内部 MoonBit 事件解析器
处理。源码来自 [moonbit-community/yaml.mbt](https://github.com/moonbit-community/yaml.mbt/tree/e2f1129249a7cc707aa1c9c39bd8bfe207c93821/src)，
固定提交 `e2f1129249a7cc707aa1c9c39bd8bfe207c93821`；MIT 许可保留在
`licenses/YAML-MIT.txt`，来源和本地改动列于 `internal/yaml/README.md`。
不使用其 JSON loader，也不依赖运行时外部 YAML 库或解释器。

根包实现 Go 的文档流切分、YAML 1.1 标量规则、JSON 键转换、重复键覆盖和
merge 展开。`y/n/yes/no/on/off` 等固定大小写拼写解析为布尔值，八进制和前缀
整数、浮点数及显式标签按参考转换；时间戳保留字符串。Base64 二进制标签经
UTF-8 替换解码。非有限数不能作为 JSON 值；作为键时使用 `.inf` 等字符串。
浮点键按 Go 的 binary32 最短十进制格式输出，扩展已有的 C locale 数值封装，
用最多九位有效数字的往返检查选取表示，并在 MoonBit 中应用 Go 的指数格式。

仅独占行且后随空白的 `---` 激活 Go reader 的流模式。每个片段只解析首个
文档；注释、空片段、末尾分隔符和后续被忽略文档均有差分输入。空字符串使
参考读取空结果数组时崩溃；本项目返回受控 Runtime，仍将该输入计为差分失败。

解析器局部修正包括：开放逐事件读取；把扫描器 lookahead 的嵌套限制接入项目
预算；采用 Go 的 plain-scalar 冒号规则；支持 NEL/LS/PS 换行；修复 verbatim
tag 扫描未前移导致的缓冲区增长；正确解码 URI 多字节转义。Go 接受标签中的
过长 UTF-8 转义，MoonBit 用替换字符维持 unknown-tag 行为，避免误识别为内建标签。

循环别名返回 Runtime。嵌套、事件处理、展开和中间 JSON 受深度、步骤及输出
预算限制；5,000 层输入及别名倍增均有受控失败测试。解析输入也受字节预算
约束。预算是执行限制，不能据此推断与无此限制的参考实现对所有大输入等价。

## 暂停与剩余范围

完整 Go 差分仍因 18 项参考崩溃返回非零；未声明通用 YAML 等价或全标准库行为
等价。不同类型的映射键转换成同一 JSON 名称时，Go map 遍历可影响碰撞结果；
诊断文本和更多 YAML 规范语料仍待验证。CLI、扩展代码参数、TLA、VM/AST、
格式化/分析工具和跨平台差距保留在[整体计划](../docs/GO-PARITY.md)。

按用户要求，本批代码和验收记录提交后暂停。仅本地提交，未推送或发布。
