## 实现契约

Go 的 TOML/YAML 使用原生函数覆盖同名 Jsonnet 源码。MoonBit 实现对照固定
v0.21.0 原生代码，来源和 Apache-2.0 许可说明已写入 NOTICE。`manifestToml`
和 `manifestYamlStream` 使用固定标准库源码封装，运行时无需 Go 解释器。

TOML 保留表、表数组、内联对象及多行数组布局；空键为 `''`，普通键按字符集
决定是否引用。字段按名字排序逐个求值和渲染，再将标量输出放到节之前，保持
副作用可见顺序。隐藏字段不读取，空对象不触发断言；拒绝 null 和函数。数值
沿用 17 位有效数字的字符串转换，非有限数值仍使用 Go 文本。

YAML 支持数组缩进和键引用选项、块字符串、文档分隔符及可选末尾标记。数字
使用最短可往返固定小数文本；字符串转义 C0/C1，但保留 HTML、U+2028/U+2029。
裸键识别保留 Go 的保留词、日期模式、大小写敏感二进制、非锚定十六进制以及
十进制下划线规则。浮点溢出会允许裸键，正常数值和下溢则引用；覆盖超大指数
和最大有限 double 附近的边界。函数值输出空串，符合原生参考行为。

Go YAML 对象分支忽略递归调用错误：最后一个字段发生错误时可以返回部分文本，
如 `{a:[1,error 'nested']}` 返回 `"a":\n- 1\n`。如果随后继续求值其他字段，
参考可能以 `Saving empty traceElement on stack` 内部崩溃。本项目保持有效 VM
状态，保留正常的部分文本结果；崩溃输入继续计为差异。深度、步骤和输出字节
限制不会被吞掉。
